## About

I like understanding how things work, then figuring out how to make them work better. At PT Inovasi Jelajah Dunia I build the company's travel eSIM app with React Native and its website with Next.js, both in TypeScript.

I graduated in Informatics from Malikussaleh University in 2024. My background in data analysis still shapes how I think about products, and outside of work I explore machine learning and NLP with Python.
